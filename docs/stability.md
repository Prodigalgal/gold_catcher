# 运行稳定性验收

系统长期运行范围为公开信源采集、Gate 行情、Java 指标、MIMO 前置摘要、内部账本、页面与数据归档。外部 API 和公开网站的短时失败必须可见并可恢复；不把容器存活、目录 available=true 或 CI 成功当作所有依赖正常。

## 发布与恢复

- GitHub CI 构建 Java / React；Release 推送不可变镜像 digest，更新 GitOps，Argo CD 同步后执行有登录的只读 API 验收。
- PostgreSQL migration 1–3 保存新闻、讨论、订单、原始行情和分钟账户样本；发布保留数据库和 PVC。备份须验证可恢复。
- 行情连接断开会新建 connection epoch，盘口以 REST 序号重新衔接。归档显示写入错误、队列和丢帧；过期价格不能因 ticker 心跳变成新报价。
- 0.4.3 将JVM堆上限改为容器内存的50%，为原生内存、线程和公开网页解析留余量。CNBC大页面最多两条并发下载/解析；堆比例不替代实际RSS、重启与采集耗时观察。
- MIMO 前置压缩默认使用独立 Flash 路线，该压缩角色不计票。MIMO Pro 另行参与辩论与裁决。429/5xx、模型不可用和超时从60秒指数退避至最多900秒；退避状态跨重启保存。可用摘要缓存继续使用，未完成的文章使用原文摘录。成功请求清除连续失败状态。
- 默认摘要单次最多75秒，块摘要和合并共享每轮100秒的剩余时间，不因两次请求叠加突破总等待范围。0.4.2 在剩余时间不足单次窗口时保存分块进度，在下一轮继续；不会用已缩短的窗口启动下一块或合并，再将自身截止时间误记为上游故障。
- 新正文优先，缓存文章按最近尝试时间轮转；发生错误的部分摘要也等待五分钟再尝试，避免一篇报告持续超时而阻塞其他新信息。
- 单篇摘要输出目标120–180字符，最多300码点；价格、指标、账务与计划数值不经摘要改写。格式通过只证明结构与长度，不能证明语义没有遗漏。

## 持续观察

通过受限验收账号设置 `GOLD_SMOKE_USERNAME` 和 `GOLD_SMOKE_PASSWORD`，不在命令行或仓库中保存密码：

```powershell
python scripts/verify_stability.py --seconds 600 --interval 20 --output artifacts/stability.jsonl
```

脚本只读状态与两个产品的 dashboard，记录37路信源、盘口序号、行情归档进度/错误/丢帧、价格新鲜度、MIMO 错误与最近成功、账本状态及实际版本。输出逐次 JSONL 和汇总 JSON；不启动研究、不改变订单或配置。`collectionPassed` 只验证采集与归档，模型错误和新鲜报价样本分别报告。固定十分钟的观察无法证明长期无故障。

同时检查 Kubernetes Pod 重启与内存、Argo Synced / Healthy、镜像 digest，以及真实页面的 PoW 登录、会话、实时更新、移动端、导出和退出。发布后再检查行情序号继续增加、历史记录与余额保留、正文/摘要缓存能恢复。

## 尚未通过的验收

更早的启动验证曾被工具策略拒绝，返回 `blocked by policy`，没有触发细节；不能据此判断为交易鉴权或模型故障。2026-10-11 已启用自动研究，0.4.5长线研究 `24205d50-dee1-47eb-b9ce-3f5be684525f` 完成四阶段与三个有效裁决，其他轮次仍有超时/格式失败。0.4.6协议、重试和恢复规则见 [research-resilience.md](research-resilience.md)，其线上整轮验收与长期可用率仍需分别记录。离线、摘要、UI和CI结果不能替代真实模型与内部订单结果。

CNBC公开盘中美债/TIPS和财经RSS为部分覆盖，报价日期/时区、首次收到与过期状态分别保留；开市连续性与首发延迟待实测。具有延迟保证的分钟级现金美债/TIPS、授权商业快讯、CME 授权深度/期权、CFD swap 结算细节仍按当前公开覆盖与未知项显示，不能用容器健康状态消除这些缺口。
