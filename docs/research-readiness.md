# 自动研究启动条件与验收边界

2026-10-11，0.4.5。三方辩论与裁决规则见 [adjudication.md](adjudication.md)。部署模式仍为 `INTERNAL_SIMULATION_ALPHA`，不接入外部下单。

## 已具备的能力

- 短线/长线间隔、产品与新闻等待时间可在“运行与配置”保存，配置持久化。
- 一个执行位供手动与自动研究共用；独立研究、交叉质疑、修订和独立裁决按封存阶段执行。
- 目录不可用、凭据缺失、推理失败冷却与备用选取已有实现；每轮选定模型后固定，MIMO、DeepSeek、Grok 同时承担研究与后续裁决；裁决一模型一票，压缩不计票。
- QWEN 已撤出。默认、短线、长线和备用配置均过滤 `qwen`，目录与推理发送层再次拒绝，大小写与空白不影响禁用。`GOLD_AI_DISABLED_PROVIDERS` 可追加其他厂商；清空该配置不能恢复 QWEN。GitOps 发布保留已有的其他禁用厂商。
- 运行页新增两个周期的路线预检、选定模型、跳过原因与目录检查时刻。读取预检不刷新目录、不调用推理、不占用研究执行位。

## 自动研究启动记录

2026-10-11 已按用户要求通过调度接口保存 `automatic=true`，短线300秒、长线1800秒。0.4.4 首个自动任务 `1a274b57-e8ec-4d82-bc72-efd01ed31f33` 实际发起三个研究请求，因超时、计划文字过长和 JSON 格式错误停在第一轮 LOW_QUORUM；该任务没有裁决、没有内部订单。调度开关已开启不等于每轮上游成功。界面保存的配置优先于环境默认，并在升级时保留。

当时 Arena/claude-sonnet-5 目录为不可用；独立 DeepSeek 备用裁决目录可用。预检按现有算法选择备用，排除与裁决同一底层模型的研究路线。目录可用不能证明真实推理成功、四阶段完成或持续稳定性。

自动启用后，调度还会等待执行位、产品行情状态、周期间隔或新闻合并时间。CFD 休市跳过短线，长线允许只做 WAIT 观察。未知执行规则和成本不因自动启用而被补造。

## 仍需独立验收的部分

1. 新版本使用真实上游完成独立研究、质疑、修订与裁决。前三阶段各至少两个不同模型有效，至少三个不同模型的裁决有效，JSON、引用、数值、期限和完整请求预算全部通过。
2. 实测四阶段耗时能够满足现有总期限：SHORT 默认240秒、LONG默认900秒。不能仅凭目录可用或短问答耗时认定满足；超时结论不会进入模拟账本。
3. 连续自动调度验证两个周期的轮转、新闻触发、供应商退避、独占执行、迟到输出与重启恢复。一次真实 WAIT 通过不等于这些条件均通过。

2026-10-08 最近的真实 Gate 研究停在 `LOW_QUORUM`，记录存在 HTTP502、结构化工具返回失败、引用无效或超时。新版本已调整结构化返回和预算处理，但尚不能用离线测试证明这些上游问题全部解决。

此前完整真实研究验证命令被工具策略拒绝，返回仅为 `blocked by policy`，未提供具体触发规则。这是工具执行拒绝，与应用调度开关、Gate HTTP认证、any2api目录状态分开记录。未通过替代入口启动同一验证，也未把静态测试记为真实研究验收。
