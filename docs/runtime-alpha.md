# 0.3.0 当前实现与验证口径

当前交易行情只使用 Gate。设计文件中的完整功能目标不等于已经实现；实际运行证据、推理可靠性和部署证据分别核验。

## Gate 行情与 Java 计算

XAU_USDT 使用官方 futures.book_ticker 与 futures.tickers。REST contracts、risk_limit_tiers、candlesticks 与 funding_rate 每60秒读取。原生数量为合约张数；Java 将数量、盘口尺寸和成交量乘以 quanto_multiplier，统一到基础 XAU 数量。价格乘基础数量才是 USDT 名义金额与盈亏。规则步长使用整张合约；杠杆采用显式标注的整数选择假设。

XAUUSD CFD 使用官方 /tradfi/symbols、/{symbol}/tickers、/{symbol}/klines。报价每秒查询，K 线每60秒；同一 K 线通道请求间隔至少300ms，报价失败指数退避。接口 timestamp 是服务器响应时间，没有最后一次 tick 时间、标记价格或盘口数量，不能伪造深度。后台使用 Gate v4 HMAC-SHA512，只调用允许的 detail 和 commissions 两个 GET；响应选择合约及费用字段，密钥和签名不进入文档、日志或前端。

两产品的六周期为1、5、15、60、240分钟与日线，每周期最多200根。只计算截止前已收盘的 K 线；API 时间单位、原始周期起点及合约单位分别转换。没有成交量的 CFD 不填零。BigDecimal/DECIMAL128 计算 SMA20、EMA20/60、Wilder RSI14、ATR14、MACD(12,26,9)、ROC12、布林带(20,2)、ATR相对价格、滚动VWAP20和成交量/20根均量；React 接收十进制字符串，Number 仅用于图表和RSI位置像素。

布林带采用20根收盘价的总体标准差；MACD柱是线减信号线，未乘2。滚动VWAP20按典型价格(H+L+C)/3乘量求和再除以量，窗口不按交易日重置。零带宽的%B无定义，零总成交量或缺少量的VWAP、量比缺失，不补造数值。Java输出结构标签、预热样本数、收盘截止与计算时间。150秒未刷新显示REFRESH_DELAYED，收盘缺口超过两根周期加120秒显示BAR_GAP，CFD休市独立显示参考状态。

Gate /spot/time 校准应用 UTC，使用单调时间保持 elapsed time。记录 RTT、误差估计和本机偏移；RTT超过800ms拒绝新样本，六分钟未校准禁止执行。不会修改宿主时钟。重连首盘口不执行开仓；重复序号不重复消费可见数量，队列溢出、迟到或断档保留状态。

## 官方信息

当前配置11个官方通道：Fed press_all/speeches、ECB press、BEA 当前发布、BLS CPI/Employment/PPI/JOLTS 四个 Atom feed，以及 BLS/BEA/FOMC 三份日历。新闻默认30秒、日历每小时，统一采用浏览器导航请求头；gzip/deflate/Brotli/Zstd 解码前后分别限制响应大小，复用 HTTP 连接。支持 ETag、去重与修订，发布/收到时间分别保存。生产 Pod 的 Java 对照请求中，旧请求头得到 BLS HTTP403；采用指定的 Edge 154 UA 及浏览器导航请求头后，Feed、ICS 和报告正文取得有效200响应。实际采集仍保留每次错误、最近成功和退避，不预先承诺长期可达。

BEA 新闻使用当前发布表中的标题、原文和带时区的时间，保留此前无时间的旧 RSS 记录并标为隔离档案，不将2013/2017年旧链接包装成近期消息。BEA 日历使用官方当前年度发布表。BLS Atom published 是 Feed 元数据时间，观察到其早于正文声明的公布时刻；用正文头部的 ET 时间核验后才进入近期研究证据，保留原 Feed 时间。ICS 的 US-Eastern 映射 America/New_York 并保留原声明。FOMC 只有会议日期范围时，scheduledAt 为空，不编造决议时刻。

正文按 Fed/BEA/ECB/BLS 的官方内容区域提取，排除导航、脚本和关联消息；Fed 会议纪要公告可继续取得其官方 HTML 纪要。ECB PDF 讲话通过 PDFBox 提取文字层，图表图片不编造成文字事实。只允许对应机构 HTTPS 主机，逐次检查重定向，Feed 响应上限1.5MB，正文响应上限4MB（PPI HTML 实测超过1.5MB），正文默认保存最多80000 Unicode 字符；超出明确标为截取。每个机构组同一时刻只获取一篇，每3秒调度，成功6小时复核、失败15分钟退避。保存正文版本、内容哈希、取得时间及截取标识，正文晚于研究截止或对应较早 Feed 版本时不作为该次研究证据。

React 信息页分为近期信息、背景资料、待核验与档案，可读取保存的正文；信源卡分别显示连接、内容和时间质量。没有 AI 有效影响判断时保持“尚无判断”，不能用关键词代替裁决。资料视图最多300篇，质量数量对应该视图；不等同历史库总量。

可选 CF/VLESS 代理使用私密订阅与 sing-box 1.14.2；容器按官方镜像 digest 固定核心。默认不启用；配置启用后，GOLD_SOURCE_PROXY_MODE 默认 FALLBACK：正常使用直接连接，403或网络故障时指定信源使用备用节点5分钟，再复核直接连接；429保留限流与退避，不通过换节点规避。PROXY_ONLY 可强制指定信源走代理。GOLD_SOURCE_PROXY_ENABLED、GOLD_SOURCE_PROXY_SUBSCRIPTION_URL、GOLD_SOURCE_PROXY_SOURCES 控制指定官方信源，行情与模型接口保持各自连接。每次订阅候选顺序随机，最多检查8个节点，验证真实 HTTPS RSS 后才启用；坏节点冷却30分钟，健康节点每5分钟复核并继续保留，网络失败才重新取订阅和切换。目标站403与节点网络故障分别记录，不把连通误报为目标可访问。节点配置仅回环监听，临时文件限定当前用户，订阅、节点凭据及地址不返回浏览器。

官方日历使用 America/New_York 和 DST，输出 UTC，再由页面显示北京时间。商业实时快讯和分钟级美国收益率仍缺失；新增公开数据的范围如下。

## 公开驱动数据与快速结构观察

2026年10月9日新增6个只读通道。Gate USIDX、EURUSD、USDJPY 公开报价每5秒读取，已收盘1分钟 K 线每60秒刷新；所有 /tradfi 公开查询共享300ms最小请求间隔。USIDX 是 Gate 美元指数 CFD，基准构成未经独立核实，不标为 ICE USDX。响应 timestamp 与收到时间分别保存，最后 tick 时刻未知；约5/15/60分钟变化的基线是目标时刻前最近的已收盘1分钟价，偏移最多2分钟，缺少有效基线则留空。

美国财政部 XML 名义及实际曲线每小时检查，输出2年/10年名义和10年实际收益率。数据本身为日频，显示官方统计日；变化为收益率百分点差乘100得到 bp，与上一可用统计日比较，允许负实际收益率。未来统计日、空值和外部 XML 实体不采纳；年初补取上一年度。检查时刻不替换首次取得这个数值版本的时刻。

Forex Factory 本周 JSON 导出每30分钟检查，只保留美元事件，包含发布、讲话和拍卖安排。提供方时间可能调整，预期方法和样本未经独立核实，导出不含实际值。未映射事件保留 forecast/previous 原文及未知单位。已支持指标的预期按百分数或人数转换，只有在正式发布前已收到、指标与单位匹配、计划与官方时刻相差最多5分钟且没有多事件歧义时，才用于差值计算。之后取得的预期不会回填历史 surprise；版本按知识时刻封存。这个端点仅提供本周，跨周未来覆盖仍有缺口。

Java 从已保存且发布时间已核验的 BLS/BEA 正文提取 CPI/核心CPI、非农、失业率、时薪、PPI、JOLTS、PCE/核心PCE 和各估计阶段 GDP。参考月份与正式公布时刻分开；人数/职位从千或百万换算，GDP 保留年化季环比，修订保留 before/after/delta。JOLTS 优先使用表格整数；只有按百万四舍五入摘要时不计算精确 surprise。模板不支持或数据缺失则保持未知。正文哈希、提取算法版本、首次收到、结构化时间与发布版本持久化；新正文或算法版本生成新的结构化版本。

每次看板刷新由 Java 生成5–15分钟、15–60分钟、1–4小时、4–48小时四周期观察，需新鲜产品报价和完整已收盘指标。当前规则以各周期收盘/EMA20/EMA60结构为主体，美元变化与日频实际收益率仅提供关联背景；冲突显示分歧。没有校准权重或预测概率。失效条件、计算时间、证据标识及缺口可见。经济事件后1/5/15分钟变化只用进程运行期间已收到的前后报价；超过10秒缺口或没有公布前基线时不确认，不用补抓K线回填。这段价格观察尚未持久化为全 tick 回放。

总览展示四周期卡片；信息页有趋势因子、经济发布、预期与覆盖、补充数据四个视图，显示统计日、时间、原值、预期、差值、修订和实际通道状态。官方新闻/日历扩为17个通道，公开财经媒体3个、公开驱动/预期9个、补充数据8个。新闻正文与发布日期的质量单独展示，RSS成功不能代替全文、数值或首发时刻验证。

日本央行 RSS 的官方链接与 URL 型 GUID 统一为 HTTPS，避免上游交替使用 HTTP/HTTPS 创建重复事件。已有别名在展示、分析和证据选择时合并：未变化内容保留最早收到时间，不同内容选择最新收到的记录；按截止时刻读取时先排除后来收到的记录。原始记录及历史研究封存不改写。

补充数据由Java采集与计算：DOL季调初请/续请和修订；Census官方指标RSS；CFTC黄金Futures Only分类持仓和管理基金净值；Fiscal Data国债拍卖安排与结果；iShares IAU发行方金衡盎司、公吨、份额和净资产；SPDR GLD官方XLSX最近两个可用统计日的黄金持仓、每份额含金量和净资产。GLD严格限制ZIP展开大小与XML实体，按实际工作表关系和字段名解析，原文件浮点尾数以十进制保留，不用Java double重新计算。每字段保留统计期/单位/实际公布或未知/首次取得/原始响应SHA-256；宏观原始文件和语义版本不可变。重复取得不改变首次知识时刻，修订生成新版本；视图从最近1000个版本选择截止时刻前、90天知识范围内的最新版本。全部研究另行封存当时的完整观察，后续更新不改历史证据。

Gate永续额外每2秒取得20档盘口和最近最多100条成交，十进制Unix秒保留纳秒。数量使用实际quanto_multiplier，Java精确计算基础XAU数量、数量失衡、样本成交量和VWAP。展示样本起止时刻、原始张数与价格。它们是REST快照/样本，尚无全量增量簿和连续逐笔回放；主动成交方向未验证。原有L1内部撮合不改变，CFD不借用永续流动性。

官方新闻新增BoE新闻/讲话、BoJ发布、EIA新闻/能源摘要/产品更新，默认30秒调度。BoE提取`.page-content`原文，EIA正文使用已核验区域，BoJ支持可提取HTML/PDF。EIA NEW为产品目录，只保存摘要和报告链接。HTTP官方旧链接仅在指定EIA/BoJ主机升级HTTPS；RSS更新时刻、未独立核验首发的Feed时间和缺失年份不会冒充正式公布时刻，也不补造年份。0.4.0 支持 XLSX 单元格和缓存公式值，日期序列按工作簿日期基准显示；未支持的其他附件格式仍显示覆盖缺口。

## any2api 上下文证据

读取了 any2api 的 `docs/reports/PROVIDER_LIMITS_AND_TURNS_BENCHMARK_2026-10-08.md`，核对 `scripts/benchmark_results_*.json` 和网关代码。非敏感摘录在 `config/context-evidence.json`，不复制账号标识或 Key。

scale 是填充文本构造参数，不是真实 token 数。scale=8000 已知正文 16320 字符、41920 UTF-8 字节，不含指令、JSON 或适配器封装。结果未保留 usage_source，因此 reportedPromptUsage 不能当作已验证 token 容量；413 也不能换算确定 token 边界。

短线与长线固定使用 MIMO（mimo-v2.6-pro）、DeepSeek（default）、Grok（grok-3）三方辩论，裁决继续由相同的三个模型以新上下文同时盲评。MIMO 保留独立的 flash 压缩请求，压缩本身不计票。当前备用路线为空，不会临时换其他厂商。QWEN 仍在路线组和发送层强制排除。完整规则见 [三模型裁决](adjudication.md)。

历史路线验证采用 balanced（MiniMax、MiMo、GLM、Arena）。切换 Gate 前的2026-10-08 run `254851cb-423a-44a0-91f1-b8f2fe05c03d`：三家首轮有效；GLM 在质疑/修订各一次 HTTP 502，两家有效观点继续；Arena 裁决有效，终态 COMPLETED / WAIT，未生成内部订单。总耗时约307秒，各次有效返回约26–96秒，请求约12–20KB / 10.7–15.7千字符。失败不被成功覆盖。

此前 Grok/LongCat 在复杂研究输入下各出现90秒等待超时；报告短问答耗时不能当作研究周期承诺。balanced 是一次可完成流程的验证，不能证明所有账号、持续可靠性或盈利能力。真实验证仅覆盖 WAIT，模拟 CREATE/部分成交/退出/费用由 Java 参考测试验证。

每路线独立校验消息数、Unicode 字符、UTF-8 字节、网关 ceil(bytes/3) 估算、输出预留、实时目录输入/输出/上下文与字符声明。16000 字符、30000 字节、10000 输入估算属于保守预算，不承诺最大容量。厂商 scoped 模型详情使用裸 ID，统一详情使用 provider/model。

supported_parameters 中的 response_format 不等于支持 JSON 模式。原生严格函数能力才使用 `submit_research`；emulated_function_bridge 使用 JSON 文本并在 Java 校验，`response_format` 需要另有明确结构化输出能力。只发送映射为 mapped 的输出别名，MiMo non_binding_only 不当作强制上限。无效格式、长度、引用或未完整返回保留错误/原文，不猜测修复。

## 多 AI 讨论与上下文

0.4.0 增加专职 MIMO 前置信息压缩。默认开启 `GOLD_COMPRESSION_ENABLED`，没有 MIMO 凭据时保留确定性摘录。`GOLD_AI_COMPRESSION_ROUTE_JSON` 为单独对象，固定 id=compressor-mimo / provider=mimo，0.4.1默认 model=mimo/mimo-v2.6-flash；不能将该角色改为另一厂商。仅 compressor-mimo 压缩角色不计票；0.4.5 默认 MIMO Pro、DeepSeek、Grok 参与辩论与裁决，备用路线为空。来源为已下载、发布时间可核验的近期 HTML/PDF 正文，XLSX 数值表不交给 LLM 压缩。

Java 按完整请求预算保守分块，0.4.6 MIMO使用 `protocol=GOLD_COMPRESSION_V1` 与 `summary=精华摘要` 两行，Java归一为 `{"summary":"精华摘要"}`，目标120–180字符，最多300码点，无需引用、编号或原文片段。指令要求保留关键事实、数值口径、事件时间、修订、否定、条件和不确定性，禁止联网补造、预测价格或给交易策略。长文章全部分块完成后，由 MIMO 合并去重；每次合并最多8份摘要，必要时逐层合并以保持预算。空结果、超长结果及额外交易字段会被拒绝；格式校验不能证明摘要语义准确。方法、指令、模型、新闻版本和正文哈希构成缓存，后台保留每次输入、输出、错误、时刻和预算。默认每次处理2个原文分块，PARTIAL 表示尚未形成全文摘要，不向下游发送局部摘要；部分完成、失败和上游不可用时保留原文摘录。上游429/5xx、超时和不可用状态从60秒开始指数退避，最高900秒；失败次数、重试时刻和最近成功请求持久化，重启继续恢复。每篇文章另有失败重试窗口，避免对待处理正文连续请求。原文下载截断仍明确显示。

研究启动后暂停并中断后台压缩，优先释放同厂商请求位。当前研究只使用截止前已经完成且正文版本相符的缓存；未处理、超时、无效或未来完成的摘要回退到原文摘录。下游新闻只替换 excerpt，不增加 compressionRef 或原文片段。preprocessing 在后台单独归档和展示，不增加一票、不让迟到摘要重写先前研究或账本。不得压缩 Java 经济数值、账户/订单、计划风险阈值；长新闻处理不会阻塞价格采集和下轮证据冻结。

独立研究→交叉质疑→修订→三方新上下文裁决。研究侧与裁决侧各按去提供方前缀、统一大小写的模型名去重；同一组三个模型允许先辩论再裁决，每个裁决模型只有一票，复用关系在 modelDiversity 和投票记录中标明。不同模型不保证错误独立。首轮共享冻结证据；后续只读取上一批封存的有效观点，三个修订观点齐全时，各裁决者的首尾阅读位置循环平衡，不按返回先后决定顺序。前三阶段每批配置三个请求，至少两份有效才继续；裁决至少三份不同模型有效，缺一份不下单。三份有效裁决需至少两票选择同一原候选方案，未形成多数则 WAIT；Java 不生成混合价格和仓位。迟到内容归档并排除。

每条消息保留摘要或厂商返回的可见分析、正式输出、引用、修订、原文、耗时、读取顺序与预算。没有可见分析时不编造。前端采用聊天室展示。

输入近七天按不同信源组优先选取、最多四项已核验发布时间的新闻摘录（默认无持仓2项、有持仓1项）、未来48小时最多六项官方日历，以及上述经济数值与提供方安排；明确标记这不是全量新闻覆盖，采集和界面保留17个官方信源。单篇正文摘录上限480字符，没有正文时使用来源摘要。选定新闻原文与正文版本另行冻结归档，不向模型直接塞入整篇报告。来源文本只作为资料；时间未知、未来公布和旧 BEA 档案不进入近期证据。原始版本、链接与正文哈希可追溯。模型取得前四个风险档位及明确范围，完整规则另存；CFD没有执行规则时只允许WAIT，不重复发送不可执行规格。可执行计划的数值与引用不截短；同伴 output/changes 摘录限制400/120字符，带归档提示，嵌套的更早轮引用留在完整讨论归档。严格函数支持时移除重复 JSON 格式样例，保留实际 schema 和语义说明。

按每条通道的字符、UTF-8字节、网关估算、声明能力与输出预留执行预算校验，不通过扩大未知容量来处理超限。超限不发送、不下单。原始账户和订单数值不静默裁剪。自动研究需显式启用，并与手动研究共用一个执行位。0.4.5 调度页显示开关状态、禁用厂商、短线/长线选定模型及各通道跳过原因；预检只读缓存目录，不刷新目录、不调用推理、不占执行位。目录可用仅代表可选路线，不能替代真实四阶段、完整请求预算和持续调度验收。

发送前以完整序列化请求计数，包含system指令、两条消息、函数schema和输出参数。实时声明的上下文扣除输出预留与512估算单位的桥接余量，再与路线输入上限取小；字符、字节和输入估算各预留10%。必要时最多三档压缩新闻摘要及同伴说明，不删同伴、不改变顺序、日期、标识、方向或金融计划。关键材料仍不能容纳时记录CONTEXT_INSUFFICIENT/NOT_SENT，不发HTTP请求。每条回复保存原始/实际材料hash、完整请求hash、前后字符/字节数、有效上限和逐字段压缩清单，聊天室和运行页面可展开核对。未知目录容量和未强制执行的输出预留仍明确标记，不能保证上游不返回413或截断。

切换Gate后的只读真实研究 `3cb76725-c838-43a0-82d0-881516703e36`（源码3174245）：独立研究与交叉质疑各有两种模型有效，修订阶段因GLM HTTP502与MiniMax不完整JSON停在LOW_QUORUM；没有裁决、没有内部订单。此记录与切换前的历史WAIT验证区分。

补充事实输入每类最多1个值（初请、零售摘要、COT净值、拍卖倍数、IAU公吨，以及新鲜的盘口失衡和带起止范围的样本VWAP），`pub:`引用映射持久化，完整观察封存。`columns/csv/common`把完全相同且已提供的元数据无损提到每行共同值；未知仍为空，不同值不合并。风险档位同样用表格保留原始数值。请求不重复传送无语义作用的证据hash，hash仍保存在研究记录和请求审计。三档可选说明压缩的同伴摘要上限240/160/40码点，金融计划、每个同伴、证据引用和原始时刻不裁剪；最终仍容纳不了时不发送。离线验证只证明指定快照的预算和阶段逻辑，不证明真实上游推理成功。

## 内部永续模拟与账务

支持 WAIT、CREATE(MARKET/LIMIT/STOP_MARKET/STOP_LIMIT)、CANCEL、CLOSE、REDUCE 和 MODIFY（退出价格、追踪止损、持有期限）。MARKET entryPrice 是买入最高/卖出最低允许成交价，余单保留至过期；属于内部语义。没有固定0.8%、止损比例、盈亏比或最低盈利门槛；数量和风险由模型提出，Java 校验规则、余额和时间。

订单等待生效延迟，只使用其后的有效买卖一，数量在内部订单间共享，退出先于开仓。使用公开 Taker 费率在开平仓各扣一次，成交为 L1 假设，不代表真实排队或券商执行证明。保证金与余单预留分别冻结，释放保证金不重复增加本金。

跨资金费边界保存当时持有数量和3秒内标记价格，再用 Gate 历史费率结算。正费率多头支付、空头收取，负费率相反；账户余额与净值使用有符号成本，结算幂等。缺少边界 mark、未知时间或报价缺口保持 costIncomplete，不能填零。简化资金费模型从账户现金扣除，未完整复刻交易所保证金消耗顺序。

新鲜 mark 与 Gate 风险档位用于简化逐仓强平，不能当作交易所精确强平复刻。没有完整历史 tick 覆盖、L2 排队位置、多实例领导权、挂单入场 AMEND 或多腿策略；改单入场用撤销后新建。单 Java 实例、单副本/Recreate；账本与事件同事务持久化，重启不重置本金，离线期间不补造成交。

CFD 已有报价、K线、实际规格和佣金只读查询。原始 swap 类型、时区与3日费字段保留，但执行语义、隔夜费类型/日历映射仍未验证，因此使用独立 USD 报价情景账本，所有结果标注观察情景和成本不完整，不计入完整成本业绩。

## 登录与验证

0.4.0 新增100档 WS U/u 衔接、REST id 初始化、断号重建与原始消息归档（gzip/Base64）；游标接口含接收时刻、源时刻和连接代次。ticker 保活不会刷新买卖一的价格年龄。归档队列/写入缺口计数与连接变化可见，CFD 只保存 REST 响应观察，无法证明完整价格路径。`GOLD_MARKET_ARCHIVE_RETENTION_DAYS` 默认7天、允许1–90天，当前生产配置为3天。发布把镜像与指定非敏感参数、资源预算同时写入 GitOps，保留已有副本数、节点选择与其他配置。

研究调度保存短线/长线间隔、产品与新闻合并等待；本轮固定独立模型，至少两份有效研究才继续。启动时默认总期限 SHORT=240秒、LONG=900秒，各 HTTP 等待取通道与总期限较小值；只对502/503/504有限重试，每次状态归档。取消、到期或重启中断均不得执行计划，CFD休市LONG只允许WAIT观察。

CFD 内部情景使用 lot×contract_volume 计算利润和保证金，按签名佣金每手每边计费；50%账户保证金水平为 Gate 文档的 Stop-Out 情景，先撤挂单再按最大亏损退出，允许余额负数。原始 swap_cost_type 不映射为猜测的 MT5 类型；POINTS/SETTLEMENT_CURRENCY/ANNUAL_PERCENT 与结算时刻必须显式配置，不明则费用未知。当前即使手动配置掉期也保留 QUOTE_SCENARIO 与成本不完整。

复盘保存分钟权益样本；休市/陈旧价格产生 null 而非零，图形断开。样本回撤只是已保存分钟观察下限，不是 tick 最大回撤。胜率、profit factor 只统计已记录完整成本样本，亏损成本可含负资金费；CFD 与报价缺口样本单列。研究统计描述调用成功、耗时与迟到，不将模型票数当作交易收益归因。CSV 防止文本字段公式注入，金融十进制保持原精度。

独立 /login 页面，admin 账号和密码从后端配置。SHA-256 PoW 默认18位，由 Web Worker 计算；挑战绑定匿名会话、单次使用、单调时间过期，密码失败提高后续难度，签发频率和状态数量受控。Basic关闭，登录轮换会话，Cookie HttpOnly/SameSite=Strict，HTTPS环境 Secure；POST必须使用CSRF，退出撤销会话。

测试覆盖参考指标、单位换算、已收盘时间、新闻XXE/修订、日历DST、封存阶段/迟到/门槛、成交与费用、资金费方向/缺失/恢复幂等、PoW会话绑定/过期/限流、CSRF和注销。发布验收单独检查 CI、镜像digest、Argo同步、版本、PoW登录以及两种Gate行情；不据此声称稳定盈利或CFD完整模拟。
