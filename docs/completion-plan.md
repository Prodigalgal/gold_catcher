# 完整运行功能交付计划

本次以当前 Gate / Java / React 系统为基础，继续使用内部账本，不添加外部下单接口。完成状态必须有测试、真实数据或线上验证依据；来源授权、官方未给出的参数和模拟执行假设分别展示。

## 验收范围

1. 官方 HTML / PDF / XLSX 正文可取得，失败不会被列表采集成功掩盖；发布、统计、收到时间不混用。
2. 行情连接与报价新鲜度分开；行情事件持久化，重启、序号、缺口和回放范围可查。
3. MIMO 专职前置原文压缩与缓存，不参与投票；其他不同模型独立研究、质疑、修订、裁决；严格上下文预算、总期限、错误记录和取消；短/长周期与新闻驱动调度可管理。
4. 永续内部订单支持撤单、修改、减仓、退出和价格跟踪；规则、费用、资金费、强平、余额与事件一致。
5. CFD 使用独立手数、佣金、账户保证金与报价观察模拟；swap 类型和结算参数有明确来源。缺少深度或费用的成绩标为估计，不加入完整成本样本。
6. 复盘包含资金曲线、回撤、收益与成本分解、持仓和模型研究结果；原始事件及 CSV/JSON 导出可核对。
7. 六个页面与独立 PoW 登录可用；配置操作只有登录与 CSRF 后开放，密钥保持服务器注入。
8. PostgreSQL 保存与恢复、健康状态、CI/CD、镜像 digest、Argo CD 及认证页面/API 验收完成。

## 外部数据依赖

优先接入有稳定公开入口的官方新闻、经济数据、跨资产行情。日频持仓、延迟行情、提供方预期各自标注。分钟级现金美债/TIPS、授权商业低延迟快讯、CME 授权深度/期权与已核实一致预期，不能用不同产品或不明来源冒充；公开入口不可用时保留原因并提供可配置接入点。

## 验证方式

Java 数值和异常情景测试；完整真实快照的四阶段请求预算；真实 any2api 返回与裁决；内部模拟确定性回放和重启恢复；React 构建与认证浏览器验收；CI、发布与线上同版本复核。真实模型的 WAIT 同样是有效结果，不能为了验收人为要求开仓。
