# Gold Catcher 页面与交互设计

设计日期：2026 年 10 月 8 日。首版采用六个主页面，桌面侧栏导航，手机采用紧凑导航。产品选择放在公共页面标题区，XAUUSDT 与 XAUUSD.s 的市场信息、费用和账户按产品切换；研究证据可共用，但成交与账务不能混合。

页面首先回答当前形势、是否有机会、依据是什么、内部订单发生了什么、最终是否盈利。输入预算、技术游标、接口响应等细节放在展开区。React 展示 Java 返回的金融数值，不在浏览器重新计算收益、保证金或投资指标。

## 六个页面

| 页面 | 路径 | 首屏重点 | 进入详情后 |
| --- | --- | --- | --- |
| 市场总览 | `/` | 报价、较长周期形势、短线机会、价格图与候选计划 | 周期、失效条件、图上事件和模拟成交；关联研究与订单 |
| 信息集合 | `/sources` | 对金价偏多、偏空、待判断与分歧的信息；官方新闻、消息流与事件窗口 | 事实、解读、影响周期、反证、已反映程度、原文与修订 |
| AI 研究 | `/research` | 当前结论、关键分歧、研究进度、适用周期和有效期 | 独立稿、匿名复核、同步修订、裁决理由、输入预算与顺序审计 |
| 模拟交易 | `/simulation` | 虚拟账户、待生效计划、内部订单、持仓和净结果 | 触价证据、部分成交、订单版本、保证金、费用、退出和强平 |
| 策略复盘 | `/review` | 净值、净收益、回撤、费用、有效样本和未知结果 | 模型与组合对比、行情分类、订单逐笔回放、前向样本评价 |
| 运行与配置 | `/operations` | 行情、信息、AI、模拟账本分别的健康状态 | 信源策略、模型通道与预算、虚拟账户配置、版本、故障和恢复 |

当前 React 原型使用本地状态切换这六个页面；正式实现采用上表路由，支持刷新和直接打开研究、计划与订单的详情链接。研究和订单详情分别使用 `/research/:runId`、`/simulation/orders/:orderId`，仍属于原有主页面。

## 市场总览

从上到下展示：

1. 产品及 Bid / Ask、点差、产品市场状态、源时间、获取时间与缺口标记。
2. 较长周期形势和短线机会。分别标注适用周期、结论时点、有效期和失效条件；较长周期看多并不意味着短线应立刻做多。
3. 左侧价格图，右侧当前判断。图显示投资指标、候选入场区、退出条件和事件标记，计划、触价与模拟成交使用不同标记。
4. 最新重要事件、候选计划与当前持仓，直接进入证据或内部交易详情。

图表展示周期提供 1m、5m、15m、1h、4h、1d。指标选择在图表内部，初始显示 EMA、成交量与用户选定的一个振荡指标，更多指标放在可展开面板。指标的名称、参数、单位、预热状态与数据可用性沿用 Java 快照。

报价实时更新；形势和研究结论按有效任务更新。报价更新不能让旧结论看起来刚刚重新分析。缺少 CFD 实际报价时显示等待接入，不画出由永续价格代替的 CFD 行情。

## 信息集合

该页面汇集行情变化、Java 指标、宏观数据、官方新闻、突发快讯和经济日历，直接展示哪些因素支持金价、哪些形成压力。默认是影响看板，消息流与经济日历作为同页视图，保留正式来源和原始事实。

| 字段 | 展示规则 |
| --- | --- |
| 方向 | 偏多、偏空、待判断、存在分歧；按选择的周期展示 |
| 事实 | 来源实际说了什么、指标实际发生了什么，与 LLM 解读分开 |
| 影响对象 | 黄金价格、波动、成交条件、净收益或保证金风险，避免混为涨跌方向 |
| 影响周期 | 数分钟、盘中或 1–2 天；较慢数据明确标为背景 |
| 支持与反证 | 影响机制、成立条件、相反证据、失效条件 |
| 可信度与时效 | 原始来源、是否核实、发布与获取时间、是否已过期 |
| 市场反应 | Java 统计事件前后实际报价变化；LLM 对是否已反映的判断另列 |
| 关联研究 | 采用该信息的研究快照、讨论意见与最终采纳理由 |

顶部列出支持、压制、待判断或分歧的去重事件数，以及综合研究的结论。条目数量不当作交易分数；同事件的重复报道合并，不把多家转载当作多个独立利多。

不强制所有信息二选一。实际值和一致预期缺失时保留待判断，模型不同意时保留分歧。未校准的模型信心不显示成精准概率。收益率、美元、风险需求与动量是相关因素，其共同作用会改变结果；示例卡片用于解释字段，并非当前市场判断。[世界黄金协会的驱动因素框架](https://www.gold.org/goldhub/research/gold-mid-year-outlook-2026)

费用上升可以压缩净收益，但不直接标成金价利空。黄金的共同背景与产品执行条件分别显示；永续的资金费与 CFD 的点差、swap 不互相替代。日频利率或 ETF 数据可用于较长周期背景，页面不把它们标成刚发生的分钟级事件。

桌面左侧消息流，右侧事件日历；窄屏优先显示即将发生的重要事件，再展示消息。消息分全部、官方、快讯、日历，支持按重要性、主题与时间查看，保留原文链接。

事件卡片展示发布时间和时区、发布机构、影响主题、前值、修订值、一致预期、实际值、预期差以及来源。未发布的实际值保持空缺，未取得授权的一致预期显示未知，不能由 LLM 补出貌似真实的数字。

快讯归并同一事件，显示原始报道、后续核实和修订。LLM 对事件的解释与来源事实分别显示。事件点击后可查看影响了哪些研究以及何时被纳入输入。总览的支持与压制因素同步链接回本页。

## AI 研究

上方固定显示结论与材料截止时间，其下显示四阶段：独立判断、匿名复核、同步修订、综合裁决。进入某阶段后同时比较参与者的结论、支持证据、反证、风险、成本和等待条件。

研究运行时显示实际完成数、截止时间、耗时与超时状态，不让模型按到达顺序占据更显眼的位置。模型名称可在审计详情中查看；匿名角色在同一研究内保持稳定。裁决同时说明采纳与未采纳理由，保留少数意见。

展开区包含原始稿与最终稿对比、消息顺序、随机种子、各通道的输入和输出预算、被省略的材料、usage 来源、响应终止原因和迟到记录。超时任务的部分结果不能显示成完整共识。

## 模拟交易

账户总览区显示期初本金、余额、净值、可用余额、冻结保证金、已实现与未实现净盈亏。每个账户明确结算币种；金额、账户收益率和保证金回报率分别注明口径。

订单列表分计划、挂单、持仓、历史，并区分尚未生效、等待触发、触价待确认、部分成交、已成交、已撤销、到期、拒绝和无法确定。触价记录不是成交记录。浮盈估值、假设退出成本和已结算费用分别展示。

订单详情提供完整事件线：研究完成 → 计划创建 → 生效 → 条件触发 → 成交评估 → 部分或全部成交 → 持仓复核 → 退出 → 结算。每一步可回到当时收到的行情、规则版本和原研究。

盈亏明细区列出成交价量、毛盈亏、开平手续费、资金费或 swap、币种换算和最终净额。点差与滑点已经进入成交价时只解释、不重复扣款。无法恢复事件先后顺序时，显示结果范围或未知状态。

操作按钮用于查看、暂停新增内部计划、撤销内部挂单、调整模拟配置。按钮不创建交易所订单，也不要求每个内部计划由人确认。配置修改显示生效时间，恢复既有持仓的退出规则。

## 策略复盘

保留完整样本：成交、撤销、未成交、等待、拒绝、超时和未知结果。展示净值、回撤、单笔期望、平均盈利与亏损、持有时间、最大有利与不利变动及强平数量。

交易净收益扣实际交易成本；系统综合结果再扣数据与 LLM 成本，两者独立显示。费用未知时，综合结果保持不完整。模型表现按产品、周期、行情、组合和版本比较，并显示样本量与时间区间。

逐笔回放保留事前材料截止，新的消息和修改按当时生效时间进入。历史回放与当时记录的前向模拟分开评价，单笔盈利不会生成模型优劣排名。

## 运行与配置

信源显示最后成功获取、源时间、延迟分布、缺口、退避、额度和下一次调度。模型显示目录状态、探针、普通推理、结构化有效率、最新有效结论、耗时和上下文预算。行情与撮合保持独立运行状态。

配置按信源、模型讨论、产品规则与虚拟账户、系统四组展示。any2api 凭据与行情账号均只在服务端，浏览器显示授权状态和脱敏名称。LLM 风险参数保留动态判断，不加入固定 0.8% 目标或统一亏损比例门槛。

发布详情显示 source commit、后端与前端版本、镜像 digest、GitOps revision、Argo 状态和接口验收结果。进程健康、模型可调用和交易研究有效分别陈述。

## 视觉与状态

采用市场终端的紧凑布局：深蓝灰或浅色背景、克制的金色点缀、数字等宽、信息层级清晰。默认跟随显示主题，正式页面提供主题与涨跌色彩习惯设置；收益同时显示符号，方向同时显示文字。

1440px 桌面展示侧栏、主图和判断面板；768px 主内容纵向排列；390px 显示紧凑导航，报价、观点、计划优先。表格必要时独立横向滚动。长标题、空状态、加载、断线、过期、超时、费用未知和样本不足均有明确呈现。

原型中的价格、曲线、指标、观点、新闻和交易金额均为设计示例。已平仓样例用数量 2、入场 4700、退出 4720 展示毛盈亏 40，示例交易费 2.20、持有成本 0.30，净收益 37.50；它没有使用真实 Bybit 费用，也不属于系统完成的模拟交易。
